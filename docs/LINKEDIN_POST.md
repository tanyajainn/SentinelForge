Built **SentinelForge**, a Python-based Windows security monitoring prototype.

The project reads Windows Event Logs, applies explainable detection rules for Defender malware alerts, suspicious account changes, service installation and failed-logon bursts, stores evidence locally in SQLite, and supports optional HTTPS notifications.

What I focused on: practical host telemetry, reproducible tests, privacy-aware alerting, and documenting detection gaps rather than promising perfect protection.

Current status: v0.1 research prototype. Next steps: persistent correlation, Sysmon/WSL telemetry, MITRE ATT&CK mapping, and evaluating detection quality and false positives in an isolated lab.
